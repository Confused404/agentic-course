# Lab notebook

One entry per experiment or surprising observation. The format matters: a prediction written
*before* you run something is the cheapest way to find out what you actually believe.

```
## YYYY-MM-DD · Node NN · <short title>
**Question:** what am I trying to find out?
**Prediction (before running):** what I expect, and how confident I am (%).
**Setup:** command / model / budget.
**Result:** numbers, trace ids, what happened.
**Why (my explanation):** mechanism, citing TEXTBOOK sections where relevant.
**Surprise score (0–3):** 0 = as predicted, 3 = my mental model was wrong.
**Follow-up:** what would I test next?
```
